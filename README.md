# Comic Vault

A comic-collection tracker: catalog what you own, track reading order, and
build wishlists and shared lists.

## Development

You need Node.js and npm.

```sh
git clone <this-repository-url>
cd comic-vault-pro
npm i
npm run dev
```

## Built with

- TanStack Start
- TypeScript
- React
- Tailwind CSS
- Supabase
